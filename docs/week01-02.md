## 导航启动说明 v0

### 已执行：离线单点接口示例

从仓库根目录运行 [README 的 Python 命令](../README.md#代码与复现)，不需要 ROS 或第三方依赖。下表保留本阶段的原始测试记录。

| 项目 | 示例固定配置 |
| --- | --- |
| 请求 | task_id=`interface-demo-001`，frame_id=`demo_map`，目标 `(1.0 m, 0.0 m, 0.0 rad)` |
| 数据来源 | `SYNTHETIC_FIXTURE` 人工测试数据；pose_source=`UNKNOWN`，不是仿真真值或算法定位 |
| 判据 | 位置误差 ≤0.1 m 且归一化 yaw 误差 ≤0.1 rad；超时 10 s；位姿最大年龄 0.5 s |
| 时间 | now_s/sample_time_s 使用同一人工或单调时间轴；输出 timestamp 是实际 UTC 生成时间，两者不混用 |
| reached | 人工注入目标处位姿，验证几何判据；输出 RUNNING→REACHED，仅 INTERFACE_ONLY |
| failed | 人工注入 wrong_frame，输出 RUNNING→FAILED，原因 frame_mismatch |
| timeout | 没有输入位姿，人工时间推进至 10 s，输出 RUNNING→TIMEOUT；不 sleep、不移动机器人 |

其他逻辑：无位姿保持 RUNNING 到超时；未来/过期位姿和坐标系不一致返回 FAILED；非有限数值、非法配置、时间倒退抛 ValueError；后端错误可调用 `fail(reason)`。到达必须同时满足位置与角度，恰到超时期限优先 TIMEOUT。枚举支持 GROUND_TRUTH/ESTIMATED，只验证标签传递，不认证来源真实性。
